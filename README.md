# Portafolio profesional

Proyecto de portafolio personal desarrollado en HTML y CSS, listo para publicarse en Vercel.

## Descripción

Este repositorio incluye una landing page personal para presentar:

- perfil profesional
- experiencia y habilidades
- proyectos destacados
- información de contacto

## Archivos principales

- `index.html`: estructura del portafolio
- `styles.css`: estilos visuales y diseño responsivo
- `README.md`: documentación del proyecto

## Cómo ver el proyecto

Puedes abrirlo localmente con un servidor web o publicarlo en Vercel.

## Deploy

El proyecto está preparado para desplegarse como sitio estático en Vercel desde GitHub.

## Enlace recomendado para compartir

El enlace principal para mostrar el portafolio al profesor o a cualquier persona es la URL pública de Vercel, por ejemplo:

`https://mi-portafolio-blue-ten.vercel.app`

Si el proyecto ya tiene dominio propio, usa ese enlace en su lugar.

## Contacto

Puedes agregar tu correo de contacto en la sección de contacto del proyecto.
